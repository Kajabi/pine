# Tooltip

Tooltips display helpful popup text when users hover over or keyboard focus on an element.

## Guidelines

#### When to use
- Use tooltips to provide additional context for elements like buttons or icons where extra explanation is helpful but not essential.
- Ideal for non-essential information that enhances understanding without cluttering the interface.

#### When not to use
- Avoid using tooltips for critical information that users need for task completion. Essential information should be visible at all times.

#### HTML Element Content

Tooltip content may contain HTML elements. In these cases,
enable the `htmlContent` property and provide your element in the `content` slot.

The open tooltip shows a copy of the slotted content, and keeps it in step: content that loads or
re-renders while the tooltip is open appears without reopening it.

- Screen readers announce updated content while the tooltip is open, so avoid content that changes
  continuously (timers, progress).
- Avoid iframes or media in tooltip content: they reload when the content changes.
- Don't rely on `id`s inside tooltip content. The tooltip shows a copy, so an `id` appears twice.

### Inside a modal or popover
When the trigger sits in an open modal dialog (`pds-modal`, or `pds-drawer` with `modal`) or an open popover, the
tooltip renders inside that dialog or popover so it shows above it. Open the modal, then hover or focus **Publish**.

## Technical Notes

- The trigger element receives `aria-describedby` referencing an ID that the component creates. Provide meaningful button/link labels so the tooltip content is read *after* the control name. When combining multiple tooltips on the same control, set `aria-describedby` manually to avoid duplication.
- Tooltips do not announce themselves automatically because they use `aria-live="off"`. Reserve tooltips for purely supplemental information and display critical validation or blocking instructions inline.
- The tooltip already opens on hover and focus, so don't wire those events yourself. Use the `opened` property when it should stay open beyond a hover or focus, such as a guided-tour step. While `opened` is set from outside, moving the pointer or focus away doesn't close it. If hover or focus opened the tooltip first, setting `opened` to `true` changes nothing, and moving away still closes it; set `opened` to `false` and then `true` to hold it open. Set it as an attribute or a property. It reflects to the attribute, so `pds-tooltip[opened]` matches an open tooltip.
- Call the public methods `showTooltip()` and `hideTooltip()` from your own script to open or close the tooltip, such as when a tour advances. Each sets `opened` and returns a promise that resolves once it's set.
- The open tooltip renders at the end of `<body>`, or inside the open modal dialog or popover around its trigger. Where it renders is decided when it opens: a tooltip opened with `opened` before its modal opens stays behind the modal until it opens again. A tooltip in a popover inside another component's shadow root, such as a `pds-filter` panel, still renders in the body.
- When `html-content="true"`, avoid placing focusable elements inside the `content` slot. Tooltips are not intended for interactive elements. If you require buttons or links, switch to `<pds-popover>`, which manages focus and dismissal affordances. Tooltip content is never a Tab stop: a focus trap such as `pds-modal`'s skips it.

```tsx
// React: keep the tooltip open while a guided-tour step points at the button
const PublishButton = ({ tourStep }: { tourStep: string }) => (
  <PdsTooltip
    content="Publish when you're ready to go live."
    placement="bottom"
    opened={tourStep === 'publish'}
  >
    <PdsButton variant="primary">Publish</PdsButton>
  </PdsTooltip>
);
```

In HTML, the tooltip below starts open. Your tour code closes it by removing `opened` or calling `hideTooltip()`.

```html
<pds-tooltip content="Publish when you're ready to go live." placement="bottom" opened>
  <pds-button variant="primary">Publish</pds-button>
</pds-tooltip>
```
