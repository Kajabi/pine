# Link

A hyperlink is used as a navigational element to direct users to another location on the website or application.

## Guidelines

### When to use

- Navigating to another page, or to a section of the current page.
- Downloading a file, with `download`.

### When not to use

- Performing an action on the current page, or submitting a form: use `pds-button`. Buttons and links can look alike, but they do different jobs: a link takes people somewhere, and a button does something where they are.

### Accessibility

- Write link text that says where the link goes, such as "Account settings" rather than "Click here". Screen reader users often move through a page's links on their own, away from the text around them.
- Always give the link text. Without it, the link shows its `href`, so people see and hear a URL.
- Inside a paragraph, use the default `inline` variant. Its underline sets the link apart from the words around it, while a `plain` link in the default color differs from body text only in weight until it's hovered.
- Set `active` on the link to the current page in a set of navigation links. It sets `aria-current="page"`.
- Check that a custom `color` has enough contrast with the background behind it.

### Active

Set `active` on the link for the current page in a nav rail or tab strip built from links. It sets `aria-current="page"` and keeps the link underlined with strong text. Mark only one link in a set as active.

### External

An `external` link is styled with an icon to indicate that it will redirect users to an external website or resource in a new tab. Screen readers hear "(opens in a new tab)" after the link text; pass a translated `externalLabel` to localize it, or an empty string to leave it out. The icon only appears with `external`, so a link that sets only `target="_blank"` announces nothing extra.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="#some-anchor" external="true"></PdsLink>',
    webComponent: '<pds-link href="#some-anchor" external="true"></pds-link>'
}}>
  <pds-link href="#some-anchor" external="true"></pds-link>
</DocCanvas>

### Target

The `target` prop specifies where to open the linked document and supports all standard target values (`_blank`, `_self`, `_parent`, `_top`). This controls link behavior independently from the `external` prop, which controls icon display.

>Note: Use `external` to show the external icon. The `target` prop only controls where the link opens.

<DocCanvas
  mdxSource={{
    react: `<PdsLink href="https://example.com" target="_blank" external>External link in new tab</PdsLink>
    <PdsLink href="/internal" target="_blank">Internal link in new tab</PdsLink>
    <PdsLink href="#section" target="_self">Opens in same frame</PdsLink>`,
    webComponent: `<pds-link href="https://example.com" target="_blank" external>External link in new tab</pds-link>
    <pds-link href="/internal" target="_blank">Internal link in new tab</pds-link>
    <pds-link href="#section" target="_self">Opens in same frame</pds-link>`
}}>
  <pds-link href="https://example.com" target="_blank" external>External link in new tab</pds-link>
  <pds-link href="/internal" target="_blank">Internal link in new tab</pds-link>
  <pds-link href="#section" target="_self">Opens in same frame</pds-link>
</DocCanvas>

### Download

Set `download` to prompt the user to save the linked file instead of opening it. Pass a filename to suggest one, or leave the value empty to keep the file's own name. Browsers ignore `download` on cross-origin URLs.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="/files/quarterly-report.pdf" download="quarterly-report.pdf">Download the quarterly report</PdsLink>',
    webComponent: '<pds-link href="/files/quarterly-report.pdf" download="quarterly-report.pdf">Download the quarterly report</pds-link>'
}}>
  <pds-link href="/files/quarterly-report.pdf" download="quarterly-report.pdf">Download the quarterly report</pds-link>
</DocCanvas>

### Font Size

The `font-size` prop can be used to adjust the size of the link text. `sm`, `md` and `lg` use the `body-xs`, `body-sm` and `body-md` font sizes (10px, 12px and 14px). `lg` is the default size.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="/privacy" fontSize="sm">Privacy policy</PdsLink>',
    webComponent: '<pds-link href="/privacy" font-size="sm">Privacy policy</pds-link>'
}}>
  <pds-link href="/privacy" font-size="sm">Privacy policy</pds-link>
</DocCanvas>

### Custom Slot Text

The text between the opening and closing tags is the link's text, and its accessible name.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="/billing">Billing and invoices</PdsLink>',
    webComponent: '<pds-link href="/billing">Billing and invoices</pds-link>'
}}>
  <pds-link href="/billing">Billing and invoices</pds-link>
</DocCanvas>

### No Custom Slot Text

When no text is provided, the link uses its `href` as its text. Avoid this fallback: people see and hear the URL instead of a description of where the link goes.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="https://example.com/help"></PdsLink>',
    webComponent: '<pds-link href="https://example.com/help"></pds-link>'
}}>
  <pds-link href="https://example.com/help"></pds-link>
</DocCanvas>

### Whole-row link

A list row where the whole row is one link. `pds-link` supports this from outside its shadow
boundary: stretch the `link` part's `::after` over a positioned ancestor.

```css
.pds-link-row { position: relative; }
.pds-link-row pds-link::part(link)::after { content: ""; position: absolute; inset: 0; }
```

The stretched box resolves its containing block against the row, not against the anchor inside the
shadow root, so `inset: 0` covers the whole row. Scope these rules to the row with a class, so they
don't stretch other links on the page.

Two things to pair with it:

- **Trailing controls need to sit above the stretched box.** Give them `position: relative` and a
  `z-index` above it, or the row's click area swallows them.
- **Give the row the focus ring, not the text.** Keyboard focus lands on the anchor inside
  `pds-link`, which is only as wide as its text, so an outline on the part hugs the words. Turn that
  outline off and outline the stretched pseudo-element instead, with the row's radius:

  ```css
  .pds-link-row pds-link::part(link)::after { border-radius: var(--pine-border-radius-md); }
  .pds-link-row pds-link::part(link):focus-visible { outline: none; }
  .pds-link-row pds-link::part(link):focus-visible::after {
    outline: var(--pine-outline-focus);
    outline-offset: var(--pine-border-width-thick);
  }
  ```

## Navigation Attributes

These props copy their value to a `data-*` attribute on the link's inner `<a>`, for client-side navigation libraries that read link behavior from those attributes. `pds-link` doesn't act on them itself, and an empty value leaves the attribute off.

| Prop | Attribute | Values |
| --- | --- | --- |
| `turbo` | `data-turbo` | string |
| `turbo-action` | `data-turbo-action` | `advance`, `replace` |
| `turbo-confirm` | `data-turbo-confirm` | string |
| `turbo-frame` | `data-turbo-frame` | string |
| `turbo-method` | `data-turbo-method` | `get`, `post`, `put`, `patch`, `delete` |
| `turbo-prefetch` | `data-turbo-prefetch` | string |
| `turbo-preload` | `data-turbo-preload` | string |
| `turbo-stream` | `data-turbo-stream` | string |
