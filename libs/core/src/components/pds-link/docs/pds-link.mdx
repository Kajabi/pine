# Link

A hyperlink is used as a navigational element to direct users to another location on the website or application.

## Guidelines

### Buttons vs Links

In many current web design patterns, buttons and links have evolved to look visually identical. However, for best practices, the fundamental differences between the two should be considered before using. Links are used to navigate the user to another page. Buttons are used to perform an action on the current page or submit a form.

### External

An `external` link is styled with an icon to indicate that it will redirect users to an external website or resource in a new tab. Screen readers hear "(opens in a new tab)" after the link text; pass a translated `externalLabel` to localize it, or an empty string to leave it out. The icon only appears with `external`, so a link that sets only `target="_blank"` announces nothing extra.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="#some-anchor" external="true"></PdsLink>',
    webComponent: '<pds-link href="#some-anchor" external="true"></pds-link>'
}}>
  <pds-link href="#some-anchor" external="true"></pds-link>
</DocCanvas>

### Target

The `target` prop specifies where to open the linked document and supports all standard target values (`_blank`, `_self`, `_parent`, `_top`). This controls link behavior independently from the `external` prop, which controls icon display.

>Note: Use `external` to show the external icon. The `target` prop only controls where the link opens.

<DocCanvas
  mdxSource={{
    react: `<PdsLink href="https://example.com" target="_blank" external>External link in new tab</PdsLink>
    <PdsLink href="/internal" target="_blank">Internal link in new tab</PdsLink>
    <PdsLink href="#section" target="_self">Opens in same frame</PdsLink>`,
    webComponent: `<pds-link href="https://example.com" target="_blank" external>External link in new tab</pds-link>
    <pds-link href="/internal" target="_blank">Internal link in new tab</pds-link>
    <pds-link href="#section" target="_self">Opens in same frame</pds-link>`
}}>
  <pds-link href="https://example.com" target="_blank" external>External link in new tab</pds-link>

  <pds-link href="#section" target="_self">Opens in same frame</pds-link>

### Font Size

The `font-size` prop can be used to adjust the size of the link text. `sm` is 12px, `md` is 14px, and `lg` is 16px. `md` is the default size.

<DocCanvas
  mdxSource={{
    react: '<PdsLink href="#some-anchor" font-size="sm"></PdsLink>',
    webComponent: '<pds-link href="#some-anchor" font-size="sm"></pds-link>'
}}>
  <pds-link href="#some-anchor" font-size="sm"></pds-link>
</DocCanvas>

### Custom Slot Text

Providing text within the open and closing tags allows the default link text to be replaced with custom text.

When no custom text is provided, the link will use the `href` as the link text.

### Whole-row link

A list row where the whole row is one link. `pds-link` supports this from outside its shadow
boundary: stretch the `link` part's `::after` over a positioned ancestor.

```css
.pds-link-row { position: relative; }
.pds-link-row pds-link::part(link)::after { content: ""; position: absolute; inset: 0; }
```

The stretched box resolves its containing block against the row, not against the anchor inside the
shadow root, so `inset: 0` covers the whole row. Scope these rules to the row with a class, so they
don't stretch other links on the page.

Two things to pair with it:

- **Trailing controls need to sit above the stretched box.** Give them `position: relative` and a
  `z-index` above it, or the row's click area swallows them.
- **Give the row the focus ring, not the text.** Keyboard focus lands on the anchor inside
  `pds-link`, which is only as wide as its text, so an outline on the part hugs the words. Turn that
  outline off and outline the stretched pseudo-element instead, with the row's radius:

  ```css
  .pds-link-row pds-link::part(link)::after { border-radius: var(--pine-border-radius-md); }
  .pds-link-row pds-link::part(link):focus-visible { outline: none; }
  .pds-link-row pds-link::part(link):focus-visible::after {
    outline: var(--pine-outline-focus);
    outline-offset: var(--pine-border-width-thick);
  }
  ```
