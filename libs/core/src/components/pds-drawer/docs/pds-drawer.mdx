# Drawer

A non-modal side panel. Unlike `pds-modal`, the page stays
interactive while a drawer is open — no dimming, no blur, no scroll lock, no
click blocking.

`pds-drawer` composes `pds-modal` internally and inherits its focus-return,
Escape and dialog semantics unchanged. It adds the edge, width and dismiss
behavior a side panel needs.

## Usage

```html
<pds-drawer open component-id="automation-settings" side="end" size="md">
  <pds-drawer-header>…</pds-drawer-header>
  <pds-drawer-content>…</pds-drawer-content>
  <pds-drawer-footer>…</pds-drawer-footer>
</pds-drawer>
```

- `pds-drawer-content` fills the panel's height by default — no copy-pasted
  height patch needed per consumer.
- `side` is logical (`start` / `end`), so RTL is free.
- `light-dismiss` (default `true`) replaces `backdrop-dismiss` — there is no
  backdrop to click, so a pointerdown anywhere outside the drawer closes it
  (in a `modal` drawer, a click on its backdrop). Setting it to `false` also
  disables Escape, matching how `backdropDismiss` gates Escape on `pds-modal`
  today.
- `initial-focus="none"` opts out of moving focus into the drawer on open —
  use it for a drawer that can open from a background event while the user
  is mid-task elsewhere on the page.

## Modal

A drawer is non-modal by default: people keep working on the page beside it.
For a task the page should wait on, such as building filters before applying
them, add `modal`. A modal drawer dims the page with a backdrop, makes the page
inert, and keeps focus inside the drawer, like `pds-modal`. It still docks to
its `side` at its `size`.

- Name it: the dialog is labelled by the element with the id
  `{component-id}-heading`, so give the drawer's heading that id.
- Always include a close control. With `light-dismiss="false"`, Escape and the
  backdrop don't close it, so the close control is the only way out.
- `modal` is read when the drawer opens. Set it before opening, not while open.
- `initial-focus="none"` doesn't apply: focus starts in a modal drawer.
- Tooltips open in `document.body`, behind a modal drawer, so they don't show
  inside one.

```html
<pds-drawer open modal component-id="contact-filters" side="end" size="md">
  <pds-drawer-header>
    <pds-text tag="h2" size="h4" id="contact-filters-heading">Filters</pds-text>
  </pds-drawer-header>
  <pds-drawer-content>…</pds-drawer-content>
  <pds-drawer-footer>…</pds-drawer-footer>
</pds-drawer>
```
