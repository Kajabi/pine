# List

A list shows a set of items of the same kind as rows, each with an optional leading visual, a title, a short description, and trailing actions. Use it for files, lessons, pages, products, or tasks.

## Guidelines

### When to use
- Show items of the same kind that people scan, open, or act on one at a time.
- Show each item with a title and at most one line of secondary information, such as a date, size, or type.

### When not to use
- Use a `pds-table` when people compare values across items, or need to sort and filter by columns.
- Use `pds-dropdown-menu` items for choices inside a menu.
- Don't use it for navigation links in a sidebar. Those are navigation, not a list of content.

### Accessibility
- The list is announced as a list, and each `pds-list-item` as an item in it.
- With `href`, the title is the item's one link, so its accessible name is the title. The whole row is clickable, but it is still a single tab stop.
- Controls in the `trailing` slot keep their own tab stop and click target. Give each icon-only button a label that names the item, such as "Download Onboarding worksheet".
- Put decorative icons in the `leading` slot with `aria-hidden="true"`. A checkbox in the `leading` slot needs its own label; use `hide-label` when the title already shows it.
- When `href` is set, the `leading` slot is part of the item's link, so a checkbox or button there can't be clicked. Put interactive controls in `trailing`, or leave `href` off for a checklist.
- Place each `pds-list-item` directly inside `pds-list`. A wrapper element between them breaks the list for screen readers.

### List items

`pds-list-item` is a row in a `pds-list`. Put the title in the default slot, and other content in the `leading`, `description`, and `trailing` slots. Empty slots take no space. The title and description each truncate to one line.

### Border, dividers, and compact

`border` draws a border around the list, `dividers` draws a rule between items, and `compact` reduces each item's padding. The list sets these for all of its items, so items in one list always match.

<DocCanvas display="block" mdxSource={{
  react: `<PdsList componentId="compact" border dividers compact>
  <PdsListItem>Onboarding worksheet</PdsListItem>
  <PdsListItem>Pricing calculator</PdsListItem>
</PdsList>`,
  webComponent: `<pds-list component-id="compact" border dividers compact>
  <pds-list-item>Onboarding worksheet</pds-list-item>
  <pds-list-item>Pricing calculator</pds-list-item>
</pds-list>`
}}>

</DocCanvas>

### In a sortable list

To let people reorder items, put each `pds-list-item` inside a `pds-sortable-item`. Reordering stays with `pds-sortable`. Outside a `pds-list`, an item lays out its row but isn't announced as a list item. Put the item's actions in its `trailing` slot rather than the sortable item's `sortable-item-actions` slot, so they line up with the rest of the row.

<DocCanvas display="block" mdxSource={{

  </PdsSortableItem>
  <PdsSortableItem>
    <PdsListItem>Lesson 2: Setting your prices</PdsListItem>
  </PdsSortableItem>
</PdsSortable>`,

## Styling

`pds-list-item` exposes two parts: `item`, the row, and `link`, the title's anchor when `href` is set. Prefer the list's `border`, `dividers`, and `compact` props over styling the parts.
