# Avatar

Avatars display a thumbnail representation of a person or organization, supporting an image, an initials fallback, and an optional badge. They can also function as a dropdown trigger.

## Guidelines

### When to use
- Use the `Avatar` to visually represent a user or entity, such as a profile picture, admin, or customer.
- Ideal for applications where identifying users or roles with a small image is needed.

### When not to use
- Avoid using for large images or media that require detailed visibility.
- Do not use for items that need a descriptive label or detailed information beyond a simple visual representation.

### Accessibility

- Set `alt` to the person's or organization's name when you set `image`, such as `alt="Demi Wilkinson"`. Use `alt=""` when the name is already shown next to the avatar, so the image is skipped rather than read as a duplicate. Without `alt`, the image has no accessible name.
- Without an `image` or `initials`, the avatar shows a generic user icon that is hidden from assistive technology. Show the person's name in nearby text, or in `triggerLabel` for a dropdown avatar.
- The `badge` is announced as "Verified". Pass `badgeLabel` to describe what it means in your product or to localize it, or an empty string to make it decorative. On a dropdown avatar, include it in `triggerLabel` instead.
- The `status` dot is announced as "online status", "away status" or "offline status". Pass `statusLabel` to localize it. On a dropdown avatar, the dot is hidden from assistive technology, so include the status in `triggerLabel` instead.

### Dropdown

Set `dropdown` to render the avatar as a button. It opens nothing on its own and has no events of its own, so slot it as the `trigger` of a `pds-popover`, as in the popover's [Trigger Slot](/docs/components-popover--docs#trigger-slot) example. Set `trigger-label` to say what the button opens; without it, the button is named "Avatar dropdown trigger".

`pds-popover` sets `aria-expanded` on the `pds-avatar` element, but the avatar doesn't pass it to its inner button, so the button's expanded state isn't exposed to assistive technology.

<DocCanvas
  mdxSource={{
    react: `<PdsAvatar dropdown={true} triggerLabel="Show profile details"></PdsAvatar>`,
    webComponent: `<pds-avatar dropdown="true" trigger-label="Show profile details"></pds-avatar>`
}}>
  <pds-avatar dropdown="true" trigger-label="Show profile details"></pds-avatar>
</DocCanvas>
