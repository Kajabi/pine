# Loader

Loaders signal that an operation is in progress via an animated spinner or typing indicator. Use them during time-consuming tasks to reassure users that the system is working.

## Guidelines

### When to use

- Display the Loader when retrieving data from an API or database to indicate that content is loading.
- Use the Loader to show that a form is being submitted.
- Implement the Loader during navigation between pages to indicate that a new page is loading.

### When not to use

- Avoid using the Loader for actions that complete quickly, as it may cause unnecessary distraction.
- Do not use the Loader for background tasks that do not require user interaction.


### Accessibility

- Put specific text in the `label` slot, such as `<span slot="label">Saving profile…</span>`. It replaces the default "Loading..." and stays available to screen readers when `show-label` is off. Text outside the `label` slot isn't shown or read.
- `pds-loader` sets no `role`. If your target screen readers don't announce the loader, announce the start and the end of the task yourself in a `role="status"` region that stays on the page. For more about live regions, see [MDN's article](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/ARIA_Live_Regions).

## Examples

### Default

By default, the prop `is-loading` is true, which displays the loader. Setting it to false will hide the loader as needed.

<DocCanvas
  mdxSource={{
    react: `<PdsLoader isLoading variant="spinner"></PdsLoader>`,
    webComponent: `<pds-loader is-loading variant="spinner"></pds-loader>`
}}>
  <pds-loader is-loading variant="spinner"></pds-loader>
</DocCanvas>

### Visible Label

The loader label is visually hidden by default, but still read by screenreaders. Set `showLabel` to `true` to make the label visible.

<DocCanvas
  mdxSource={{
    react: `<PdsLoader isLoading showLabel variant="spinner"></PdsLoader>`,
    webComponent: `<pds-loader is-loading show-label variant="spinner"></pds-loader>`
}}>
  <pds-loader is-loading show-label variant="spinner"></pds-loader>
</DocCanvas>

"Loading..." is the fallback content of the `label` slot. To show your own text, put it in a `<span slot="label">`.

<DocCanvas
  mdxSource={{
    react: `<PdsLoader isLoading showLabel variant="spinner"><span slot="label">Saving profile…</span></PdsLoader>`,
    webComponent: `<pds-loader is-loading show-label variant="spinner"><span slot="label">Saving profile…</span></pds-loader>`
}}>
  <pds-loader is-loading show-label variant="spinner"><span slot="label">Saving profile…</span></pds-loader>
</DocCanvas>

### Loader Size

Set `size` to a preset, `xs` (24px), `sm` (32px), `md` (48px, the default), `lg` (64px) or `xl` (80px), or to a custom CSS length. The `typing` variant ignores `size`.

### Typing

Setting the `variant` prop to `typing` will display a typing loader. This loader is not affected by any changes to the `size` prop. Use it to show that someone, or something such as an assistant, is writing a reply.

<DocCanvas
  mdxSource={{
    react: `<PdsLoader isLoading variant="typing"></PdsLoader>`,
    webComponent: `<pds-loader is-loading variant="typing"></pds-loader>`
}}>
  <pds-loader is-loading variant="typing"></pds-loader>
</DocCanvas>

## Technical notes

`pds-loader` sets its ARIA attributes on its own element as `is-loading` changes:

- `aria-live="polite"` is always set.
- While `is-loading` is true, `aria-busy="true"` is set.
- When `is-loading` is false, `aria-busy` is removed, `aria-hidden="true"` is set, and the loader is visually hidden.
