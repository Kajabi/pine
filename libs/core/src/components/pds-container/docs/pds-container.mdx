# Container

Container constrains its children to a semantic max-width, centering them within the available space. Use it to wrap form panels, settings pages, and full-page flows.

## Guidelines

### When to use

- Form panels and dialogs where content should be narrower than the viewport
- Settings pages and content areas that need a consistent reading width
- Page-level wrappers that cap the maximum site width

### When not to use

- To divide content into columns. Nest a `pds-row` inside the container and size its `pds-box` columns.
- To add side gutters. Container adds no padding, so on screens narrower than its max-width its content runs edge to edge. Put a `pds-box` with `padding` inside it.
- To stack, space or align content. Use `pds-box`.

### Accessibility

- `tag` sets the element rendered inside the container's shadow root. `tag="main"` renders a `main` landmark, and a page should have only one, so use it for the page's primary content.
- `tag="section"` renders a `section` with no accessible name, so it isn't exposed as a region landmark. Start it with a heading so readers know what the content is.
- `aria-label` on `pds-container` labels the host element, not the inner `main`, `section` or `article`, so it doesn't name the landmark.

## Examples

The examples put a `pds-box` with a background inside each container to show its width. A `pds-box` is only as wide as its content unless it has `fit`, so each one sets `fit`.

### Default

Without a `size`, the container grows to fill its parent with no max-width constraint.

<DocCanvas
  display="block"
  mdxSource={{
    react: `import { PdsBox, PdsContainer, PdsText } from '@pine-ds/react';

<PdsContainer>
  <PdsBox fit backgroundColor="var(--pine-color-background-inset)" padding="md">
    <PdsText tag="p">No max-width applied.</PdsText>
  </PdsBox>
</PdsContainer>`,
    webComponent: `<pds-container>
  <pds-box fit background-color="var(--pine-color-background-inset)" padding="md">
    <pds-text tag="p">No max-width applied.</pds-text>
  </pds-box>
</pds-container>`
  }}>
  <pds-container>
    <pds-box fit background-color="var(--pine-color-background-inset)" padding="md">
      <pds-text tag="p">No max-width applied.</pds-text>
    </pds-box>
  </pds-container>
</DocCanvas>

### Not Centered

Set `centered="false"` to align the container to the start of its parent instead of centering it.

<DocCanvas
  display="block"
  mdxSource={{

<PdsContainer size="md" centered={false}>

    <PdsText tag="p">Left-aligned — centered=false.</PdsText>
  </PdsBox>
</PdsContainer>`,
    webComponent: `<pds-container size="md" centered="false">
  <pds-box fit background-color="var(--pine-color-background-inset)" padding="md">

</pds-container>`

### Semantic Tag

Use `tag` to render the inner container as a semantic HTML element.

<DocCanvas

    <PdsText tag="h2">Page title inside tag="main"</PdsText>
  </PdsBox>
</PdsContainer>`,
    webComponent: `<pds-container size="lg" tag="main">
  <pds-box fit background-color="var(--pine-color-background-inset)" padding="md">

  </pds-box>
</pds-container>`
