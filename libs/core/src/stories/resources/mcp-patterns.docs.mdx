# Admin composition patterns

Verified page-level Pine recipes for admin screens: page headings with actions, tables in cards, list pages with and without filters, settings forms, and loading and empty states. Use these when assembling or migrating an admin screen — not when looking up individual component props.

> **Source of truth:** `libs/core/src/stories/resources/mcp-patterns.json` is consumed by Storybook (this page) and by the [Pine MCP](../?path=/docs/resources-pine-mcp--docs) (`list_pine_patterns` / `get_pine_pattern`). Edit the JSON in Pine; do not duplicate recipes in pine-mcp.
