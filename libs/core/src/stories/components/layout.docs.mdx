# Layout

Three components handle page layout. `pds-container` caps content at a readable max-width. `pds-row` and `pds-box` divide content into a responsive 12-column grid. `pds-box` also spaces and aligns content on its own, outside the grid.

## Rules

- Columns are `pds-box` elements placed directly inside a `pds-row`. Size them with `size` props on the `pds-box`. `pds-row` has no size or offset props.
- A row's column sizes should add up to 12. A column that doesn't fit on the line wraps to the next one.
- Columns with no size share the width the sized columns leave, equally.
- `size` applies at every width. `size-sm`, `size-md`, `size-lg` and `size-xl` apply from their breakpoint up, and `size-xs` applies only below 576px. Below the breakpoint of its size props, a column is full width, so the columns stack.
- `size-*="0"` hides a column. `offset-*="0"` removes an offset and hides nothing.
- `col-gap` sets the gutter as padding inside each column, and without it columns have no gutter. Put borders, backgrounds and shadows on a `pds-box` inside the column, not on the column itself.
- `flex="grow"`, `flex="shrink"` and `flex="none"` don't size a column inside `pds-row`. They put the column on its own full-width line. Use `size` props for columns, and flex props on a `pds-box` inside another `pds-box`.

The breakpoints are `xs` (below 576px), `sm` (576px and up), `md` (768px and up), `lg` (992px and up) and `xl` (1200px and up).

## pds-box on its own

A `pds-box` stacks or lines up its children and spaces them with `gap`, so a single-column layout needs no grid. A `pds-box` is only as wide as its content until you set `display="flex"`, which makes it fill its container.

## pds-container and the grid

`pds-container` caps its content at a max-width and centers it. Set `size` to `sm` (340px), `md` (520px), `lg` (700px), `xl` (1064px), `full` (1440px), or any CSS length such as `640px`. Without `size` it has no max-width. Nest a `pds-row` inside it when you also need columns.

Here the columns split at 768px and stack below it. Each column holds a bordered `pds-box`, so the border sits inside the gutter that `col-gap` adds.

<DocCanvas client:only
  mdxSource={{
    react: `
import { PdsBox, PdsContainer, PdsRow } from '@pine-ds/react';

<PdsContainer size="lg">
  <PdsRow colGap="sm">
    <PdsBox sizeMd="8">
      <PdsBox border padding="md">Main content</PdsBox>
    </PdsBox>
    <PdsBox sizeMd="4">
      <PdsBox border padding="md">Sidebar</PdsBox>
    </PdsBox>
  </PdsRow>
</PdsContainer>
`,
    webComponent: `
<pds-container size="lg">
  <pds-row col-gap="sm">
    <pds-box size-md="8">
      <pds-box border padding="md">Main content</pds-box>
    </pds-box>
    <pds-box size-md="4">
      <pds-box border padding="md">Sidebar</pds-box>
    </pds-box>
  </pds-row>

`

## Offsetting columns

`offset` moves a column toward the end of the row by a number of columns, from `0` to `12`. Breakpoint versions such as `offset-md` work like the size props. In right-to-left text the offset comes from the right.

  </PdsBox>
  <PdsBox sizeMd="4" offsetMd="4">

## Alignment

Inside a `pds-box`, `justify-content` aligns children along its direction and `align-items` across it. Set `display="flex"` so the box fills the width, and a `min-height` when you align children vertically, since a box only grows as tall as its content.

<DocCanvas client:only
  mdxSource={{
    react: `
import { PdsBox } from '@pine-ds/react';

<PdsBox display="flex" alignItems="center" justifyContent="center" minHeight="120px" border>
  Centered
</PdsBox>
`,
    webComponent: `
<pds-box display="flex" align-items="center" justify-content="center" min-height="120px" border>
  Centered
</pds-box>
`
}}>
  <pds-box display="flex" align-items="center" justify-content="center" min-height="120px" border>Centered</pds-box>
</DocCanvas>

## Troubleshooting

### A column wraps to a new line

The sizes on that line add up to more than 12. Columns that don't fit wrap to the next line, so check the sizes that apply at the current viewport width.

### Borders or backgrounds run into the gutter

The border or background is on the column itself. `col-gap` is padding inside each column, so move the styling to a `pds-box` inside the column. To change the gutter, set `col-gap`, or `col-gap-inline` and `col-gap-block` for one direction.

### Columns stay side by side on phones

The columns use the base `size`, which applies at every width. Use a breakpoint size such as `size-md` so they stack below that breakpoint.

### A column with a flex prop jumps to its own line

`flex="grow"`, `flex="shrink"` and `flex="none"` give a column inside `pds-row` its full width. Remove the flex prop and set a `size` instead. Flex props work as expected on a `pds-box` inside another `pds-box`.
