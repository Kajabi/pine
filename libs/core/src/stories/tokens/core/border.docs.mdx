## Radius

Pine has no core radius tokens. Three of the semantic radius tokens point at core dimension tokens: `--pine-border-radius-sm` is `--pine-dimension-050` (4px), `--pine-border-radius-md` is `--pine-dimension-125` (10px) and `--pine-border-radius-lg` is `--pine-dimension-200` (16px). `--pine-border-radius-full` is 9999px. Use the `--pine-border-radius-*` tokens in your styles, listed on <pds-link href="?path=/docs/design-tokens-semantic-borders--docs">Semantic Borders</pds-link>.
