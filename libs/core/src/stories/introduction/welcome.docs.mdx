# Building with Pine
Pine is a design system of web components, React wrappers and design tokens for building accessible interfaces. Each `pds-*` component works as a plain HTML tag in any page or framework, and through `@pine-ds/react` in React apps. The `--pine-*` tokens let your own markup match the components.

These docs explain when to use each component and show live examples in both formats, along with every property, event and method.

## Where to start

- [Getting Started](/docs/introduction-getting-started--docs): install Pine from the CDN or npm and render your first component.
- [Component status](/docs/resources-component-status--docs): every component and its lifecycle label. Each component has its own page under **Components** in the sidebar.
- [Design Tokens](/docs/design-tokens-tokens--docs): the color, spacing and typography values behind the components.
- [Pine MCP](/docs/resources-pine-mcp--docs): connect an AI coding assistant to Pine's components, tokens and icons.
- [Contributing](/docs/introduction-contributing--docs): set up the repository and open a pull request.
- [Get Support](/docs/introduction-get-support--docs): report a bug, request a feature or ask a question.
