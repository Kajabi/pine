# Building with Pine
Pine is a design system of web components, React wrappers and design tokens for building accessible interfaces. Each `pds-*` component works as a plain HTML tag in any page or framework, and through `@pine-ds/react` in React apps. The `--pine-*` tokens let your own markup match the components.

These docs explain when to use each component and show live examples in both formats, along with every property, event and method.
