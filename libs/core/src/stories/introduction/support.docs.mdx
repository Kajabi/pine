# Get Support

Pine is maintained by its contributors. It has no dedicated support team or assigned stewards, so there's no set response time for issues or questions. The `@Kajabi/dss-devs` code owners review pull requests (see [CODEOWNERS](https://github.com/Kajabi/pine/blob/main/.github/CODEOWNERS)).

## Report a bug or request a feature

[Open a GitHub issue](https://github.com/Kajabi/pine/issues/new/choose) and pick the template that fits:

- **Bug Report** for a component that doesn't work as documented
- **Feature request** for a new component, prop, variant or token
- **Accessibility Issue** for an accessibility or usability problem

Search the [existing issues](https://github.com/Kajabi/pine/issues) first. To fix something yourself, see the [Contributing guide](/docs/introduction-contributing--docs).

## Find an answer in the docs

- Each component's page under **Components** covers when to use it, live examples and its full API.
- The [changelogs](/docs/resources-changelog--docs) list what changed in each release.
- For **component lifecycle** labels (stable / beta / deprecated), see [Component status](/docs/resources-component-status--docs). For **RTL and localization** expectations, see [RTL and localization](/docs/guides-rtl-and-localization--docs).
- The source code lives on [GitHub](https://github.com/Kajabi/pine).

## Kajabi-internal channels

Kajabi staff can also ask in Slack. These links only open inside Kajabi's Slack workspace.

- [#ds-support](https://kajabi.slack.com/archives/C01A424HY8Y) is for help requests and support questions
- [#design-system-discussion](https://kajabi.slack.com/archives/C046HHS5KTN) is for general design systems conversation and collaboration
- [#dss-pine-mcp](https://kajabi.slack.com/archives/C0922PA4509) is for discussions and support related to the Pine MCP

Design system issues are also tracked on the Kajabi-internal [DSS Linear board](https://linear.app/kajabi/team/DSS/all).
