# Get Support

Pine is maintained by its contributors. It has no dedicated support team or assigned stewards, so there's no set response time for issues or questions. The `@Kajabi/dss-devs` code owners review pull requests (see <pds-link href="https://github.com/Kajabi/pine/blob/main/.github/CODEOWNERS" external>CODEOWNERS</pds-link>).

## Report a bug or request a feature

<pds-link href="https://github.com/Kajabi/pine/issues/new/choose" external>Open a GitHub issue</pds-link> and pick the template that fits:

- **Bug Report** for a component that doesn't work as documented
- **Feature request** for a new component, prop, variant or token
- **Accessibility Issue** for an accessibility or usability problem

Search the <pds-link href="https://github.com/Kajabi/pine/issues" external>existing issues</pds-link> first. To fix something yourself, see the <pds-link href="../?path=/docs/introduction-contributing--docs">Contributing guide</pds-link>.

## Find an answer in the docs

- Each component's page under **Components** covers when to use it, live examples and its full API.
- The <pds-link href="../?path=/docs/resources-changelog--docs">changelogs</pds-link> list what changed in each release.
- For **component lifecycle** labels (stable / beta / deprecated), see <pds-link href="../?path=/docs/resources-component-status--docs">Component status</pds-link>. For **RTL and localization** expectations, see <pds-link href="../?path=/docs/guides-rtl-and-localization--docs">RTL and localization</pds-link>.
- The source code lives on <pds-link href="https://github.com/Kajabi/pine" external>GitHub</pds-link>.

## Kajabi-internal channels

Kajabi staff can also ask in Slack. These links only open inside Kajabi's Slack workspace.

- <pds-link href="https://kajabi.slack.com/archives/C01A424HY8Y" external>#ds-support</pds-link> is for help requests and support questions
- <pds-link href="https://kajabi.slack.com/archives/C046HHS5KTN" external>#design-system-discussion</pds-link> is for general design systems conversation and collaboration
- <pds-link href="https://kajabi.slack.com/archives/C0922PA4509" external>#dss-pine-mcp</pds-link> is for discussions and support related to the Pine MCP

Design system issues are also tracked on the Kajabi-internal <pds-link href="https://linear.app/kajabi/team/DSS/all" external>DSS Linear board</pds-link>.
